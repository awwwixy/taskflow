# TaskFlow

Трекер щоденних завдань і продуктивності.

## Можливості

- додавання справ з пріоритетом, позначка «виконано», видалення
- сортування за важливістю або часом додавання
- пошук справ
- статистика й прогрес
- «Челендж дня» і мотиваційні фрази
- вхід і збереження «в хмару»
- імпорт великого архіву з можливістю скасування

## Технології

HTML5, CSS3, Vanilla JavaScript (ES-модулі), без фреймворків.

## Структура

```
lib/     бібліотека taskflow-lib (окремий пакет)
demo/    демо-проєкт з прикладами використання бібліотеки
js/      код застосунку
css/     стилі
```

## Бібліотека taskflow-lib

| Модуль | Призначення |
|---|---|
| `generators.js` | нескінченний генератор, ітератор з тайм-аутом |
| `memoize.js` | мемоізація: LRU, LFU, TTL, власна стратегія |
| `priority-queue.js` | двостороння черга пріоритетів |
| `async-array.js` | асинхронний `filter`: колбек і Promise, скасування |
| `archive.js` | поступова обробка великих даних (async-ітератор) |
| `event-emitter.js` | події: підписка, відписка, канал помилок |
| `base-client.js`, `*-proxy.js`, `sync-service.js` | HTTP-клієнт, проксі авторизації, логування й ліміту |
| `logger.js` | декоратор логування |

## Запуск

```bash
npm install
cd demo && npm install && cd ..
```

- **Застосунок:** відкрити `index.html` через Live Server.
- **Демо:** `node demo/index.js`
